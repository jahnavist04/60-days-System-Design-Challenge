# Day 3 — APIs & HTTP Basics

## What is an API?

API stands for **Application Programming Interface**.

An API allows different software components to communicate with each other.

Instead of directly accessing another system's internal code or database, an application can use an API to request data or perform an operation.

For example, when you use a weather application:

```text
Mobile App
    |
    | API Request
    ↓
Weather API
    |
    ↓
Weather Data
    |
    ↓
Mobile App
