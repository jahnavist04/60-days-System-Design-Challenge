# Day 2 - Client-Server Architecture

## What is Client-Server Architecture?

Client-server architecture is a model where the **client** sends requests to a **server**, and the server processes those requests and sends back a response.

For example, when you open Instagram:

- Your phone acts as the client.
- Instagram's servers receive your requests.
- The server processes the request.
- The server sends the required data back to your phone.

A simple representation is:

```text
Client
  |
  | Request
  ↓
Server
  |
  | Response
  ↓
Client
